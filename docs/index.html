Dot count / Dim others / Matches only
1K / 3K / 5K sets the most dots drawn; a cap is greyed out when a smaller one already shows every household. Dim others draws a fixed random sample of all households and dims the ones that don't match your filters, so the same dots stay put as you click around. Matches only draws only households that match your filters, up to the cap; useful for a narrow slice, where you want to see that group's own spread.

ACS or CPS
Two Census Bureau surveys, switchable at the top right. The ACS is about 20 times larger, so it can show states, metro areas, local areas and narrow slices reliably, and it has housing costs. The CPS asks about income in far more detail, so income sources such as pensions and investments are measured better; it is the official source for national income. When a slice exists in both, the sidebar shows the other survey's figure too.
